Use Develop in Swift Tutorials to help you build great apps.

Explore how Develop in Swift Tutorials can take you through the full cycle of app development. Go from designing and building simple apps to enhancing your apps with intelligent features and more.

  3. Create a project
  4. New: Discover coding intelligence

SwiftUI

Get familiar with some of the tools and technologies you’ll use to create apps.

Chapter 1 Explore Xcode

Get to know Xcode and SwiftUI by creating a prototype of a messaging app. Learn about syntax for Swift and how to use the source editor and preview.

  1. Welcome to SwiftUI
  2. Hello, SwiftUI
  3. Wrap-up: Explore Xcode

Chapter 2 Views, structures, and properties

Learn how to build a custom view to create a multiday weather forecast. In your view, you’ll use properties to customize the display for each day.

  1. Customize views with properties
  2. Wrap-up: Views, structures, and properties

Chapter 3 Layout and style

Build two onboarding screens for an iOS app to learn useful tools for putting views where you want them onscreen and inspecting their size. Define colors in the asset catalog and use them to create gradient backgrounds.

  1. Design an interface
  2. Wrap-up: Layout and style

Chapter 4 Buttons and state

Explore adding buttons to your apps. Learn about Swift closures and their relationship to buttons. Use state properties to update the user interface automatically.

  1. Update the UI with state
  2. Wrap-up: Buttons and state

Chapter 5 Lists and text fields

Create a dynamic interface that stores a set of items in an array and displays them using lists. Use text fields and bindings to let people enter text.

  1. Create dynamic content
  2. Wrap-up: Lists and text fields

Data modeling

Model real-world concepts and relationships by creating and testing your own custom types.

Chapter 1 Custom types and Swift Testing

Define your first data model by making your own custom types, and prove they work correctly with unit tests. Then use your custom types to keep track of scores in a game.

  1. Welcome to data modeling
  2. Model data with custom types
  3. Wrap-up: Model data with custom types
  4. Add functionality with Swift Testing
  5. Wrap-up: Custom types and Swift Testing

Chapter 2 Models and persistence

Build a list of your friends’ birthdays, using SwiftData to save and retrieve that data across launches.

  1. Save data
  2. Wrap-up: Models and persistence

Chapter 3 Navigation, editing, and relationships

Create an app to track friends and their favorite movies using SwiftData to manage the model objects. Use a query to display the items in a list, and make a detail view to edit them. Then learn how to create and display relationships between friends and movies, and explore how to create advanced queries.

  1. Navigate sample data
  2. Wrap-up: Navigate sample data
  3. Create, update, and delete data
  4. Wrap-up: Create, update, and delete data
  5. Work with relationships
  6. Wrap-up: Navigation, editing, and relationships

Chapter 4 Observation and shareable data models

Power an alphabet game using Observation. Share a complex data model with many independent views.

  1. Complete a game with logic
  2. Wrap-up: Observation and shareable data models

Chapter 1 Views and data storage

Build a screen to capture text and photo data. Use SwiftData to save entries and build a custom view to display them.

  2. Review Swift fundamentals
  3. Collect, model, and store data
  4. Use a custom layout view
  5. Wrap-up: Views and data storage

  1. Create an algorithm for badges
  2. Wrap-up: User experience features

Chapter 3 App refinement

  1. Add inclusive features
  2. Investigate and fix a bug
  3. Wrap-up: App refinement

  3. Wrap-up: Windows in visionOS

  2. Wrap-up: Ornaments and multiple windows
